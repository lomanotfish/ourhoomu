# Retention ทุกประวัติและแผน restore

## Ready gate

ยังไม่เริ่มงาน ผู้ใช้อนุมัติเฉพาะเอกสาร ต้องยืนยัน design revision/ขอบเขตนี้ก่อน พร้อม prerequisite tickets ที่ Tech Lead ตรวจรับจริง ไม่ใช่แค่ runtime succeeded

- Owner: backend-engineer; ไม่ใช่ assignment/dispatch ที่เกิดขึ้นแล้ว
- Scope / allowed edits: ourhoomu-api retention function/jobs/tests และ runbook; platform ช่วย configuration ตาม ticket ย่อยที่ Lead จัด
- Contracts: [requirements](../requirements.md), [domain](../../project/domain.md), [API v0.1](../../project/api-contract.md)
- Dependencies: SW-0004, SW-0006, SW-0007, SW-0008
- Worktree/branch/base SHA/target: Tech Lead เติมจาก receipt จริงก่อนเปลี่ยน ready; ใช้ worktree แยกตาม ownership และตรวจ target ณ เวลานั้น ห้ามใช้ SHA ของเอกสารเป็นฐานถาวร
- ทุก worker ไม่ได้ทำงานคนเดียวใน repo รักษางานของผู้อื่นและขอบเขตไฟล์ ไม่ revert ผลของ ticket อื่น
- Shared migrations/lockfile/contract ต้องมี owner เดียว หากต้องเปลี่ยนส่วนของ owner อื่นให้ Tech Lead จัด assignment ก่อน
