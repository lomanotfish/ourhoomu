# LINE OA push เมื่อยืนยันการจ่ายเงิน

## Ready gate

ยังไม่เริ่ม application implementation รอ full design/ผู้รับข้อความ/binding/ข้อความและ retention สำเนา LINE ยืนยัน พร้อม prerequisite ที่ Tech Lead ตรวจรับจริง Credentials รอผู้ใช้; ไม่มีการสมัคร/ซื้อ/ส่งข้อความเอง

Scope: ourhoomu-api LINE webhook/binding/outbox/worker/tests; schema/shared contracts ให้ Tech Lead จัด ownership กับ data/frontend ก่อน dispatch ไม่แก้ไฟล์ผู้อื่นโดยพลการ ไม่ revert งานของผู้อื่น ไม่เปลี่ยนสิทธิ์ดูสลิป

Contracts: [LINE OA](../../project/line-oa.md), [requirements](../requirements.md), [domain](../../project/domain.md), [API](../../project/api-contract.md)

## Acceptance

- [ ] SW-0018-AC1: ผูก/ยกเลิกปลายทางตาม policy ที่ผู้ใช้ยืนยัน; webhook signature/raw body/redelivery ถูก; forged destination และ cross-house binding ถูกปฏิเสธ ตรวจ binding/สมาชิกสดก่อนส่ง
- [ ] SW-0018-AC2: เงินโอนและเงินสดตาม scope ที่ยืนยัน enqueue confirmed event/outbox atomic ครั้งเดียวต่อ payment/destination; pending/rejected/self-covered ไม่แจ้ง รวมงวด 40+60 และ concurrent/reconcile retry
- [ ] SW-0018-AC3: secrets server-only; ไม่มีภาพสลิป/เลขบัญชีในข้อความหรือ logs; ใช้ retry key เดิม จำกัด window/attempts/quota; timeout/429/5xx/blocked/invalid-token ไม่ย้อนเงินหรือสร้างเครดิตใหม่ ไม่อ้าง accepted ว่า read/delivered
- [ ] SW-0018-AC4: outbox/delivery metadata ไม่เกิน parent expiry, revoke/expiry ยับยั้ง queued retry, restore ไม่ replay และ scope สำเนา LINE ผ่านการตัดสินใจด้าน retention
- [ ] SW-0018-AC5: fixture/integration checks ผ่าน และ credentialed push ไปปลายทางทดสอบที่อนุญาตจริงผ่าน; quota/plan ตรวจแล้ว ไม่นับ mock เป็น real integration
