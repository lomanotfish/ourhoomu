## กลุ่ม flow และหน้าจอที่ต้องมี

จัดหน้าใน Figma file เดียวให้นำทางง่าย โดยสร้าง flow map และ design foundations ก่อน แล้วแยก flow ต่อไปนี้เป็น Section/Group ที่มี screen frames ตั้งชื่อสื่อความหมาย:

1. Authentication และบ้าน: login Google/Apple, cancel/error, invite ค้าง, invite ใหม่/หมดอายุ/ใช้แล้ว, สร้าง/เข้าบ้าน, 0/1/หลายบ้าน, switch house, สมาชิกถูกนำออกและกลับเลือกบ้าน
2. ภาพรวมและ activity: dashboard, balances/pending actions, กิจกรรมและ in-app inbox, foreground refresh, offline/stale timestamp และ retry
3. บิลและส่วนแบ่ง: สร้าง draft, เท่ากัน/เปอร์เซ็นต์, validation % ต่ำ/เกิน 100, rounding, เลือกผู้รับ/recipient account แบบ masked, ไม่มีบัญชี, preview ผู้รับที่ไม่ใช่ creator/self-covered, publish/success/conflict/failure, bill detail และสิทธิ์สมาชิก
4. การจ่ายและสลิป: จ่ายบางส่วน/ทั้งหมดด้วยโอนหรือเงินสด, upload, pending/delay/reconcile/retry/cooldown, approved/rejected/mismatch/duplicate/quota/error, ยอดคงเหลือ, cash pending/creator confirm/reject พร้อมเหตุ, creator != recipient, slip access/expiry/removal/retention warning; ห้ามสถานะ pending ดูเหมือนจ่ายสำเร็จ
5. เวร: วันนี้/สัปดาห์, รายการ/รายละเอียด, สร้างและแก้ schedule ทั้งจัดเอง/ทำซ้ำ/หมุนอัตโนมัติ, rotation order, preview 2 สัปดาห์, เปลี่ยนเฉพาะอนาคต, unassigned, complete/undo และ activity
6. บ้านและสมาชิก: member list/roles, invite create/copy/revoke/expired/reused/accepted, join success, leave/remove guard เมื่อมีรายการค้าง, home name/timezone proposal annotation
7. บัญชีรับเงิน: list/add/edit/default/disable ของเจ้าของบัญชี, masked display, ไม่มีบัญชีและทางไปตั้งค่าก่อน publish; ห้าม UI เปิดดู/แก้บัญชีแทนสมาชิกคนอื่น
8. LINE OA: connect/binding/unlink, recipient DM/group choice, message preview และ delivery failure โดยแยกข้อเสนอที่ยังรอยืนยัน และแสดงว่าการแจ้ง LINE ล้มเหลวไม่เปลี่ยนสถานะการจ่าย
9. Settings/account: locale Thai/English, profile, privacy/retention, logout และ request account deletion; แสดงเวลาลบ/ข้อมูลใกล้หมดอายุอย่างชัดเจน
10. Shared system/accessibility states: loading/empty/error/retry/offline/session expiry/forbidden/removed membership/expired content และ form validation ที่เกี่ยวข้องในแต่ละ flow ไม่รวมไว้เป็นหน้าตัวอย่างลอย ๆ อย่างเดียว
