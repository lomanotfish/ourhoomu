## Acceptance

- Implement the accepted IssuerAdapter input/output in core-api-contract.md.
  Use a maintained cryptographic JWT/JWKS verifier compatible with Workers;
  source versions and APIs from official docs. Do not implement cryptography.
- Require explicit trusted server configuration for provider, issuer, audience,
  JWKS and allowed algorithms. Missing configuration fails closed. Token claims,
  request bodies and token header URLs cannot choose a network destination or
  change issuer/provider policy. Production JWKS transport requires HTTPS.
- Verify signature, algorithm, issuer, audience, expiry/not-before, subject,
  nonce and acceptable auth time. Map only issuer+subject; no email linking.
  Public errors expose no token, key, email or upstream raw error.
- Inject JWKS retrieval for deterministic cryptographically signed tests; no
  HTTP localhost production exception, fake actor route or hardcoded production
  identity. Cover wrong key/alg/issuer/audience/nonce, expired/future token,
  missing claims, unconfigured provider, key rotation and attacker jku/x5u.
- Test-first proof plus fresh frozen install/typecheck/format/lint/unit tests.
  Playwright remains browser/HTTP acceptance framework; this security unit test
  complements it and cannot prove Google/Apple/native login.
- Commit owned files and a durable report with exact commands/results, source
  URLs, SHA, Graft/runtime evidence and limitations. Independent review before
  integration. Live issuer/Managed Auth/native compatibility stays gated; do not
  change identity provider or remote Auth settings.
